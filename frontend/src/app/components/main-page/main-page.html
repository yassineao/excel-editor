Zum Arbeitsbereich ↑
Wie starte ich?

Wähle „Neue Arbeitsmappe“ für eine leere Tabelle oder „Excel-Datei importieren“ für eine vorhandene Datei. Deine Arbeitsmappen findest du anschließend in deiner Sammlung.

Welche Dateien kann ich importieren?

Du kannst Excel-Dateien im Format .xlsx und .xls auswählen. Für den Import wird deine Datei an den Server übertragen; dieser muss erreichbar sein.

Wo bleiben meine Arbeitsmappen?

Deine Sammlung wird in diesem Browser gespeichert und beim nächsten Besuch wieder geladen. In einem anderen Browser oder auf einem anderen Gerät ist sie nicht automatisch verfügbar. Wenn du die Website-Daten löschst, wird auch die gespeicherte Sammlung entfernt.

Kann ich mehrere Tabellenblätter nutzen?

Ja. Füge innerhalb einer Arbeitsmappe weitere Blätter hinzu und wechsle zwischen ihnen. Nicht mehr benötigte Blätter kannst du entfernen; mindestens ein Tabellenblatt bleibt erhalten.
